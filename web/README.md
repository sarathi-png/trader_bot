# Quotex Signal Bot - Web Dashboard

A real-time trading signal dashboard built with Next.js and WebSocket.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Deployment

This project is designed for Vercel deployment:
```bash
vercel deploy
```

## Architecture

- Next.js 14 with App Router
- TypeScript
- Tailwind CSS
- WebSocket connection to bot on port 8765
- Real-time signal updates
- Confluence meter visualization
- Live trading chart
- Performance tracking
